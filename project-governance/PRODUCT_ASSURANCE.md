# Current Project Product Assurance Profile

核心体验：`“这是我自己查出来的。”`

Investigation Loop：DETECT → SCAN → EVIDENCE → HYPOTHESIS → SIMULATE → DECIDE → VERIFY → DEBRIEF。

Product pressure：player bypasses evidence、hypothesis has no effect、NOVA reveals answer、investigation becomes quiz、agency lost、repeated UX patching。

触发：`PRODUCT_ASSUMPTION_PRESSURE → Product Reassessment`。
