# AEGF Roadmap

## INFRA-001A — Governance Core & Project Profile V1

优先：Task Contract、Risk、Architecture Governance、Review/Retry、Acceptance Freeze、Evidence/State、DoD、Delivery、Design Pressure、Human Attention、Basic Event/Timing、Project Profile。

不做：具体技术标准、Full Context Router、AI Test Planner、Parallel Scheduler、Dashboard、Published Package。

## INFRA-002 — Context, Token & Validation Efficiency

Context Router / Context Budget / Change Impact / Selective Validation / Validation Tiers / Review Depth / Decision & Engineering Memory。

## INFRA-003 — Autonomous Quality Loop

AI Test Planner / Failure Router / Controlled Retry / Finding→Regression automation / Async CI / Human Attention Queue。

## INFRA-004 — Multi-Agent Orchestration

Task Compiler / Worktree Orchestrator / DAG Scheduler / Parallel Builders / Merge Queue / Capability Router。

## INFRA-005 — Control Plane & Telemetry

Task visualization / stage duration / lead time / token-cost / review cycles / architecture pressure / human intervention / evidence drill-down。

## Later

Personal Architecture Standards Library、Frontend/Java/Python/Integration/Data/Security/Platform Profiles、Release Profiles、Skill Library、MCP Integrations、Cross-project Governance。

原则：Design broad / Implement narrow / Use real tasks / Measure / Revisit / Extract when proven。
