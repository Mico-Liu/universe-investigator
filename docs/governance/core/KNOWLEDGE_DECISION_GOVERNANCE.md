# Knowledge & Decision Governance

## Decision Memory

保存：Decision / Context / Why / Alternatives / Evidence / Consequences / Revisit Trigger。

## Engineering Memory

记录 pitfall / lesson / reusable rule / failure pattern。

```text
ADR = why we chose X
Engineering Memory = what we learned and should not repeat
```

聊天不是长期知识存储。成熟经验应沉淀为 ADR / Governance Rule / Task Contract / Regression Test / Engineering Memory。
