# Agentic Engineering Governance Framework

本目录定义可跨项目复用的 Agentic Engineering Governance Framework（AEGF）设计基线。

核心目标：

```text
大框架
+
小步实现
+
可组合 Profile
+
证据驱动
+
架构优先
+
效率优先
+
工具可替换
```

框架不绑定某一种 Agent、MCP、Skill、CI、语言或技术栈。

## 核心能力域

1. Task Governance
2. Architecture Governance
3. Quality Governance
4. Review / Retry Governance
5. Delivery Governance
6. Efficiency Governance
7. Observability / Control Plane
8. Evidence / Audit
9. Knowledge / Decision Governance
10. Environment / Capability Governance
11. Risk / Assurance Governance
12. Cost / Capacity Governance

## 最高原则

```text
Artifact-driven > Conversation-driven
Deterministic-first
Baseline Once, Validate Incrementally
Risk-triggered Assurance
Evidence-driven Escalation
Bounded Review / Retry
Repeated Friction Is Evidence
Push != Delivery Complete
Agent Cannot Self-declare DONE
Reference Externally, Own the Model Internally
```
