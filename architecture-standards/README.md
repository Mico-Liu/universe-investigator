# Architecture Standards Extension Point

未来可复用、可组合的个人 Architecture Standards Library 扩展点。当前不实现具体 React / Java / Python 等技术标准。

```text
Generic Architecture Governance
+ Composable Architecture Profiles
+ Project-specific Constraints
```

See the generic [architecture profile model](../docs/governance/profiles/ARCHITECTURE_PROFILE_MODEL.md) and the current [project architecture profile](../project-governance/ARCHITECTURE_PROFILE.md).
